## 2. 화면 흐름

```
                 ┌──────────── 상단 메뉴 (모든 화면) ────────────┐
                 │   플레이어        경기 기록        팀 나누기    │
                 └──────┬───────────────┬────────────────┬───────┘
                        ▼               ▼                ▼
S01 홈 ──redirect──▶ S02 목록        S06 목록          S09 참가자 선택
                     │   │             │   │                │ 10명 선택
              [등록] │   │ 이름 클릭   │   │ [보기]         ▼
                     ▼   ▼             │   ▼            S10 결과 ──[다시 나누기]──▶ S10
                   S03  S04 상세       │  S08 상세          │
                     │   │  │          │   │ [삭제]         │ [이 팀으로 경기 기록]
              저장 → S02 │  │[삭제]→S02│   └──────▶ S06     ▼
                         │  │          ▼                 S07 (자리가 채워진 상태)
                  [수정] ▼  │        S07 경기 기록 ◀──────────┘
                        S05 │          │ 저장
                  저장 → S04            └──────▶ S08
```

- 저장, 수정, 삭제가 성공하면 이동한 화면 위쪽에 초록색 안내 문구(플래시 메시지)를 한 번 보여준다.
- 입력 오류가 있으면 이동하지 않고 같은 폼을 다시 보여준다 (입력값 유지, 빨간 안내 문구).

## 3. 공통 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│ ▰ INHOUSE 내전 매니저       플레이어   경기 기록   팀 나누기 │  ← 헤더 (현재 메뉴 강조)
├─────────────────────────────────────────────────────────────┤
│ ✔ 플레이어를 등록했습니다.                                   │  ← 플래시 메시지 (있을 때만)
│                                                             │
│ 화면 제목                                    [주요 버튼]     │
│                                                             │
│ 본문                                                        │
└─────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
|---|---|
| 테마 | e스포츠 중계 스코어보드 느낌 (2026-11-25 확정). 차콜 바탕 `#0b0d12`에 블루 진영(왼쪽), 레드 진영(오른쪽) 빛과 은은한 사선 무늬, 포인트 앰버 `#ffb800`. 대회나 방송사 로고는 쓰지 않는다. |
| 글꼴 | 한글 제목은 Google Fonts `Black Han Sans`, 숫자와 영문(로고, 포지션, VS, 스탯)은 `Oswald`, 나머지와 작은 한글은 시스템 글꼴 |
| 헤더 | 검은 띠 + 아래쪽 블루→앰버→레드 선. 현재 메뉴는 비스듬한 앰버 판 |
| 본문 폭 | 최대 1080px, 가운데 정렬, 좌우 여백 16px |
| 제목 | 앞에 비스듬한 앰버 막대 |
| 팀 색 | 블루 `#1f7bff`, 레드 `#ff3355`. 팀 이름은 꽉 찬 색 띠, 레드팀은 좌우를 뒤집어 블루팀과 마주 보게 한다(휴대폰 폭에서는 뒤집지 않음). 두 팀 사이에 큰 "VS" |
| 승/패 표시 | 배지 글자는 "승리/패배"이지만 화면에는 VICTORY(파랑)/DEFEAT(빨강)로 보인다. 최근 경기 줄도 승리는 파랑, 패배는 빨강 띠 |
| 오류 문구 | 붉은 글씨, 입력칸 바로 아래 |
| 넓은 표 | 휴대폰 폭에서는 표만 가로로 스크롤된다 (페이지 전체는 스크롤되지 않음). |
| 버튼 | 비스듬한 판. 주요 버튼은 앰버, 삭제 버튼은 붉은색이고 누르면 브라우저 확인창을 띄운다. |

구현: `templates/fragments/layout.html`(head, header 조각), `static/css/style.css`

> 2026-11-25에 LoL 테마, OP.GG 테마와 테마 전환 버튼을 시험했지만, 사용자가 중계 테마만 남기기로 했다.

### S03 플레이어 등록 / S05 플레이어 수정
```
플레이어 등록 (수정 화면은 "플레이어 수정")
이름        [               ]
            이름을 입력하세요.            ← 오류일 때
라이엇 ID   [ 이름#태그     ]
주 포지션   [ 선택하세요   ▼]
부 포지션   [ 없음         ▼]
            [등록] (수정 화면은 [저장])   [취소]
```
| 항목 | 규칙 | 오류 문구 |
|---|---|---|
| 이름 | 필수, 최대 30자 | 이름을 입력하세요. / 이름은 30자 이하로 입력하세요. |
| 라이엇 ID | 필수, 최대 50자, 중복 불가 | 라이엇 ID를 입력하세요. / 이미 등록된 라이엇 ID입니다: {ID} |
| 주 포지션 | 필수 | 주 포지션을 선택하세요. |
| 부 포지션 | 선택 ("없음") | - |
| 취소 | 등록 화면은 S02로, 수정 화면은 S04로 이동 | - |
| 성공 | 등록하면 S02로 이동, 수정하면 S04로 이동 + 플래시 메시지 | - |

│ 12경기  7승 5패  승률 58%            │
└──────────────────────────────────────┘
포지션별 전적
┌──────────┬──────┬──────┐
│ 포지션   │ 경기 │ 승률 │   ← 기록이 있는 포지션만
│ ADC      │  9   │ 67%  │
│ SUPPORT  │  3   │ 33%  │

┃ JUNGLE   [플레이어 선택 ▼]     ┃ JUNGLE   [플레이어 선택 ▼]

| 항목 | 규칙 | 오류 문구 |
|---|---|---|
| 경기 날짜 | 필수, 기본값 오늘, 미래 불가 | 경기 날짜를 입력하세요. / 미래 날짜는 기록할 수 없습니다. |

| 플레이어 없음 | 등록된 플레이어가 10명 미만이면 폼 위에 안내 문구와 S03 링크 | - |

### S09 팀 나누기: 참가자 선택
```
팀 나누기
참가할 10명을 고르세요.                         선택 3 / 10
⚠ 참가자를 정확히 10명 골라 주세요. (현재 3명)        ← 오류일 때
┌───┬────────┬──────┬──────┬──────┐
│☐전체│ 이름 │ 주   │ 부   │ 승률 │   ← 머리줄 "전체" 체크박스
│ ☑ │ 김철수 │ TOP  │ JUN  │ 50%  │
│ ☐ │ 홍길동 │ MID  │ -    │  -   │
└───┴────────┴──────┴──────┴──────┘
[팀 나누기]
```
- 머리줄의 "전체" 체크박스로 모든 플레이어를 한 번에 고르거나 해제한다. 일부만 골랐으면 "전체" 칸은 가로줄(-) 상태가 된다.
- "선택 n / 10"은 체크할 때마다 바뀐다 (작은 JavaScript). JavaScript가 없어도 서버에서 10명인지 다시 검사한다.
- 오류로 돌아오면 이전에 고른 체크 상태를 유지한다.
- 폼은 GET으로 보낸다 (데이터를 바꾸지 않으므로 새로고침해도 안전).

### S10 팀 나누기: 결과
```
팀 나누기 결과
점수 차이 0.04  (블루 2.61 : 레드 2.57)

┃ 블루팀  점수 2.61              ┃ 레드팀  점수 2.57
┃ TOP     철수   주              ┃ TOP     지훈   부
┃ JUNGLE  영희   주              ┃ JUNGLE  수빈   -      ← 주/부/- = 포지션 적합도
┃ …                              ┃ …

[이 팀으로 경기 기록]   [참가자 다시 고르기]
```
| 항목 | 설명 |
|---|---|
| 점수 | 레이팅 합 (요구사항명세서 3.3), 소수점 둘째 자리 |
| 적합도 표시 | 주 포지션이면 "주", 부 포지션이면 "부", 둘 다 아니면 "-" (회색) |
| 이 팀으로 경기 기록 | S07을 `blue`, `red` 파라미터로 미리 채워서 연다. |
| 참가자 다시 고르기 | 같은 참가자가 체크된 상태로 S09를 연다. |
