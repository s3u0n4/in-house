## 2. 화면 흐름

```
                 ┌──────────── 상단 메뉴 (모든 화면) ────────────┐
                 │   플레이어        경기 기록        팀 나누기    │
                 └──────┬───────────────┬────────────────┬───────┘
                        ▼               ▼                ▼
S01 홈 ──redirect──▶ S02 목록        S06 목록          S09 참가자 선택
                     │   │             │   │                │ 10명 선택
              [등록] │   │ 이름 클릭   │   │ [보기]         ▼
                     ▼   ▼             │   ▼            S10 결과 ──[다시 나누기]──▶ S10
                   S03  S04 상세       │  S08 상세          │
                     │   │  │          │   │ [삭제]         │ [이 팀으로 경기 기록]
              저장 → S02 │  │[삭제]→S02│   └──────▶ S06     ▼
                         │  │          ▼                 S07 (자리가 채워진 상태)
                  [수정] ▼  │        S07 경기 기록 ◀──────────┘
                        S05 │          │ 저장
                  저장 → S04            └──────▶ S08
```

- 저장, 수정, 삭제가 성공하면 이동한 화면 위쪽에 초록색 안내 문구(플래시 메시지)를 한 번 보여준다.
- 입력 오류가 있으면 이동하지 않고 같은 폼을 다시 보여준다 (입력값 유지, 빨간 안내 문구).

```
└─────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
|---|---|
| 관리자 메뉴 | 헤더 오른쪽 끝 작은 글씨. 로그인 전 "관리자"(S12로 이동), 로그인 후 "로그아웃" 버튼. 로그인하면 메뉴에 "승인 대기 n"(빨간 숫자, 0이면 숫자 없음)과 "휴지통"이 추가된다 |
| 관리자 전용 버튼 (2026-11-26) | 로그인하지 않으면 숨긴다: S02 "목록 수정", S04 "수정"·"삭제", S06 "+ 경기 기록", S08 "삭제", S10 "이 팀으로 경기 기록". S02의 "+ 플레이어 등록"은 "+ 등록 신청"으로, S03 제목·버튼은 "등록 신청"·"신청"으로 바뀐다 |
| 테마 | 깔끔한 흰색 + 하늘색 (2026-11-28, 그 전의 e스포츠 중계 다크 테마를 대신함). 아주 옅은 하늘색 바탕 `#f3f8fd`, 흰 카드(둥근 모서리 12px, 옅은 그림자), 포인트 하늘색 `#0ea5e9`(글자는 `#0284c7`). 색은 `style.css`의 `:root` 변수 |
| 글꼴 | Pretendard (jsDelivr에서 받음), 없으면 시스템 글꼴 |
| 헤더 | 흰 띠 + 아래 옅은 선, 스크롤해도 위에 붙어 있다(휴대폰 폭은 아님). 현재 메뉴는 옅은 하늘색 알약 모양 |
| 본문 폭 | 최대 1080px, 가운데 정렬, 좌우 여백 16px |
| 가운데 배치 (2026-11-28) | 모든 화면: 제목·설명·버튼 줄, 소제목, 설명 문단, 랭킹 탭, 전적 요약 숫자, 플래시 문구를 가운데로 (제목 줄의 버튼은 제목 아래). 표와 대진표는 본문 폭 그대로. S03/S05 등록·수정과 오류 화면: 폭 760px 카드 하나를 화면 가운데에 (`main.narrow`). S12 로그인: 폭 540px의 큰 카드(입력칸 높이 54px, 버튼 52px)를 화면 가로·세로 가운데에 (`main.auth`) |
| 팀 색 | 블루 `#2563eb`, 레드 `#ef4444`. 팀 이름 줄은 옅은 파랑/빨강 바탕, 레드팀은 좌우를 뒤집어 블루팀과 마주 보게 한다(휴대폰 폭에서는 뒤집지 않음). 두 팀 사이에 동그란 "VS" |
| 승/패 표시 | "승리"(옅은 파랑)/"패배"(옅은 빨강) 알약 배지. 최근 경기 줄 왼쪽에 파랑/빨강 띠 |
| 오류 문구 | 붉은 글씨, 입력칸 바로 아래 |
| 넓은 표 | 휴대폰 폭에서는 표만 가로로 스크롤된다 (페이지 전체는 스크롤되지 않음). |
| 버튼 | 둥근 모서리. 주요 버튼은 하늘색, 나머지는 흰 바탕 + 테두리, 삭제 버튼은 붉은 글씨(마우스를 올리면 붉은 바탕)이고 누르면 브라우저 확인창을 띄운다. |

구현: `templates/fragments/layout.html`(head, header 조각), `static/css/style.css`

> 2026-11-25에 LoL 테마, OP.GG 테마와 테마 전환 버튼을 시험했지만, 사용자가 중계 테마만 남기기로 했다.
> 2026-11-28에 사용자 요청("깔끔한 기준으로 흰색과 하늘색")으로 중계 테마를 흰색 + 하늘색 테마로 바꿨다.

### S02 플레이어 목록
```
플레이어 목록                                       [+ 플레이어 등록]
┌────────┬──────────────┬────────┬──────┬──────┬────┬───┬───┬──────┐
│ 이름   │ 라이엇 ID    │ 주 라인 티어 │ 주   │ 부   │경기│ 승│ 패│ 승률 │
├────────┼──────────────┼────────┼──────┼──────┼────┼───┼───┼──────┤
│ 이선용 │ 성아는…#2993 │ 다이아 │ ADC  │ SUP  │ 12 │ 7 │ 5 │ 58% │
│ 홍길동 │ Hong#KR1     │ -      │ MID  │ -    │  0 │ 0 │ 0 │  -   │
└────────┴──────────────┴────────┴──────┴──────┴────┴───┴───┴──────┘
주 라인 티어 = 주 포지션의 라인별 티어. 티어마다 색이 다른 배지, 마스터 이상은 "마스터 350LP"처럼 LP도. 없으면 "-"
라인별 티어를 아직 안 넣은 사람은 이름 옆에 작은 회색 글씨 "라인 티어 미입력"
(없을 때) 등록된 플레이어가 없습니다.
```
| 항목 | 설명 |
|---|---|
| 이름 | 누르면 S04 상세로 이동 |
| 부 포지션 | 없으면 "-" |
| 승률 | 소수점 없이 반올림한 %. 경기가 없으면 "-" |
| 정렬 | 등록 순 |

### S03 플레이어 등록 / S05 플레이어 수정
```
플레이어 등록 (수정 화면은 "플레이어 수정")
이름        [               ]
            이름을 입력하세요.            ← 오류일 때
라이엇 ID   [ 이름#태그     ]
주 포지션   [ 선택하세요   ▼]   부 포지션 [ 없음 ▼]
┌ 라인별 티어 ───────────────────────────────────────┐
│ 라인마다 본인이 생각하기에 어느 티어 정도로 하는지… 마스터 이상은 LP를 적으면 더 정확해요 │
│ 탑 [선택▼] 정글 [선택▼] 미드 [마스터▼] 원딜 [선택▼] 서폿 [선택▼] │   ← 휴대폰은 2칸씩
│                         [LP (선택)]                    │   ← 마스터 이상을 고른 칸만
└────────────────────────────────────────────────────┘
            [등록] (수정 화면은 [저장])   [취소]
```
| 항목 | 규칙 | 오류 문구 |
|---|---|---|
| 이름 | 필수, 최대 30자 | 이름을 입력하세요. / 이름은 30자 이하로 입력하세요. |
| 라이엇 ID | 필수, 최대 50자, 중복 불가 | 라이엇 ID를 입력하세요. / 이미 등록된 라이엇 ID입니다: {ID} |
| 라인별 티어 5칸 | 모두 필수, 아이언 ~ 챌린저. 팀 나누기에 쓴다 (2026-11-26. 같은 날 솔랭 티어 칸은 없앴다) | 탑 티어를 선택하세요. (라인마다) |
| LP | 마스터 이상을 고른 라인만 보인다(자바스크립트). 선택, 0~3000. 마스터 아래로 바꾸면 비운다. 서버도 마스터 아래 티어의 LP는 버린다 | LP는 0 이상으로 입력하세요. / LP는 3000 이하로 입력하세요. |
| 주 포지션 | 필수 | 주 포지션을 선택하세요. |
| 부 포지션 | 선택 ("없음"). 주 포지션과 같으면 안 된다 (2026-11-26) | 부 포지션은 주 포지션과 다르게 골라 주세요. |
| 잘못된 형식 | LP에 숫자가 아닌 값, 목록에 없는 티어·포지션 값 (주소 조작 등). `messages.properties`의 typeMismatch 문구 | 숫자(정수)만 입력하세요. / 목록에 있는 값을 골라 주세요. |
| 취소 | 등록 화면은 S02로, 수정 화면은 S04로 이동 | - |
| 성공 | 등록하면 S02로 이동, 수정하면 S04로 이동 + 플래시 메시지 | - |

### S12 관리자 로그인 (2026-11-25 추가)
```
관리자 로그인
⚠ 아이디 또는 비밀번호가 맞지 않아요.      ← /login?error
아이디    [            ]
비밀번호  [            ]
[로그인] [취소]
```
- 헤더 오른쪽 작은 "관리자" 글씨로 들어온다. 로그인하면 S15 승인 대기로 이동하고, 헤더에 "승인 대기"·"휴지통" 메뉴와 "로그아웃"이 생긴다.
- 로그인하지 않은 채 관리자 전용 화면(수정, 경기 기록, 승인 대기, 휴지통, H2 콘솔) 주소로 들어오면 이 화면으로 보낸다.
- 로그아웃하면 S02 플레이어 목록으로 이동한다.

### S15 승인 대기 (관리자 전용, 2026-11-26 추가)
